# Public Profile — Zero-Trust Claim Contract

This repository is a public professional identity surface. Every statement is a market-facing claim and should be supportable by actual work.

## Zero-trust publication rule
Do not trust AI summaries, generated profile copy, repository badges or historical plans as proof of a capability, client result, employment, certification, revenue or production system. Inspect the linked repository or work product before publishing a claim.

## Claim controls
- Distinguish demonstrated work from interests, learning, prototypes and future goals.
- Never invent employers, clients, revenue, credentials, adoption, testimonials or certifications.
- Link to real artifacts and state what each artifact proves and does not prove.
- Remove private client data, personal secrets, credentials, tokens and internal control-plane details.
- A README edit is materially public-facing and requires a review packet under docs/evidence/ with claim ID, source links, verification, limitations and exact revision.

The CI gate verifies structure, required profile sections and known secret/placeholder patterns. It does not prove external repository availability, the truth of every claim or actual market perception. Human review remains required.
